### Prepare for Zinier Java Full Stack Developer Interview

#### Key Skills to Focus on:
- Core Java fundamentals (OOP, exceptions, collections)
- Spring Boot and REST API development
- Frontend frameworks (React or Angular)
- HTML, CSS, JavaScript basics
- Database concepts (SQL, NoSQL, ORM tools like Hibernate)

***

### Common Interview Questions for Fresher Java Full Stack Role

**Java / Backend Questions:**
- What is Java Full Stack Development? Explain the tech stack you use.
- What are the OOP principles? Examples in Java.
- Difference between checked and unchecked exceptions.
- Explain collections framework, difference between ArrayList and LinkedList.
- What is a Java Stream API?
- What are Java 8 features?
- Explain Spring Boot and its main components.
- How do you create RESTful APIs? Describe HTTP methods like GET, POST, PUT, DELETE.
- How to handle exceptions in Spring Boot?
- What is dependency injection?
- Basic SQL queries and joins.
- What is Hibernate or JPA?

**Frontend Questions:**
- HTML semantic tags?
- Difference between class and id in CSS?
- React vs Angular? Basics of React lifecycle or Angular components.
- How does React use states and props?
- How to connect frontend with backend API?

**General Full Stack Questions:**
- Explain MVC architecture.
- What is the role of a build tool like Maven or Gradle?
- Explain JWT and how to secure REST API.
- Version control concepts — branches, pull requests, merge conflicts.
- What is CORS and how to handle it?

### Tips for Your Interview
- Brush up on **Java core concepts** and coding problems (arrays, strings, loops).
- Practise explaining your code clearly. Use examples.
- Prepare to demo simple full stack projects if asked.
- Review **Spring Boot basics for REST APIs** and connecting services.
- Don’t forget frontend basics with **React or Angular**.
- Understand **how the full stack fits together** (frontend-backend-database).
- Show enthusiasm to learn and adapt.
